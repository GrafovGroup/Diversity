## Typography

- Family: **Inter Variable**, Roman, full character set; supports Latin and extended Latin for English and French.
- Local file: `public/fonts/inter-variable.woff2` (352,240 bytes).
- Official project: <https://rsms.me/inter/> and <https://github.com/rsms/inter>.
- Exact source file: <https://raw.githubusercontent.com/rsms/inter/master/docs/font-files/InterVariable.woff2>.
- License: SIL Open Font License 1.1; exact upstream license bundled at `public/fonts/OFL-Inter.txt`, retrieved from <https://raw.githubusercontent.com/rsms/inter/master/LICENSE.txt>.
- Self-host this file. Do not add a Google Fonts network request. Suggested CSS: `font-family: Inter; font-style: normal; font-weight: 100 900; font-display: swap; src: url('/fonts/inter-variable.woff2') format('woff2');`.

## Inspection

All ten downloaded photos were opened in a contact sheet for visual inspection. The files match the described subjects. WebP files are distinct, no placeholder content or watermark is present, and stock photography is not used as a testimonial or consultant portrait. The font file was identified as a valid WOFF2 TrueType file by the runtime’s file-type check. Font glyph decoding through Python was unavailable because its optional Brotli decoder was not installed; language coverage is supported by the upstream full Inter distribution, with rendering to be verified in browser QA.
