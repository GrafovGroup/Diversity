# Changelog

## 1.0.0 — October 31, 2026

Initial website implementation for review; not a production-release announcement.

- Added a static Astro and TypeScript website with English and Canadian French routes.
- Added the full gradient Diversity.ca wordmark, typography, responsive layouts and accessible navigation patterns.
- Added seven service divisions, 21 subservices, corporate and public-sector journeys, supporting business pages and original insights content.
- Added segmented enquiry forms with optional Formspree submission, an honest email-draft fallback and local enquiry-record export.
- Added canonical/language metadata, sitemap, robots policy, a 404 page and local visual assets.
- Added build, formatting and browser-test commands and a GitHub Actions validation workflow.
- Added source/provenance notes, content-review requirements and WHC static-deployment instructions.

Automated results are recorded by the test run and QA report. Brand/content approvals, verified business details, legal review, real form delivery and production approval remain separate release gates.
