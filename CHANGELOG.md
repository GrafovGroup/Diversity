# Changelog

## 1.0.1 — 31 October 2026 — Formspree integration

- Connected the owner-approved `xaeepeno` endpoint to all eight EN/FR enquiry routes, with a build-time override.
- Kept dependency-free vanilla JavaScript AJAX and added native HTML POST context for visitors without JavaScript.
- Added subject, language, intake and source-path fields, duplicate-submission protection, busy state and context restoration after successful submission.
- Added mocked acceptance/rejection/network/timeout tests and static checks for all eight form destinations.
- Updated bilingual privacy disclosures and operational documentation. Inbox delivery remains to be verified; public launch and DNS changes remain unapproved.

## 1.0.0 — 31 October 2026 — approval preview

- Implemented approved Gradient Modern #9 identity with complete outlined light/dark SVG wordmarks, typographic favicon and bilingual social assets.
- Built 114 English/Canadian French content routes plus a bilingual 404, including seven divisions, 14 subservices, corporate and government journeys, procurement, industries, 13 regions and three editorial guides.
- Added four accessible segmented intake flows, email-draft fallback, JSON export, consent, anti-spam field, endpoint validation, submission error states and language-aware service selection.
- Added local licensed photography and typography, keyboard/reduced-motion features, responsive layouts, draft notices and a printable provisional service overview.
- Implemented canonical/hreflang metadata, grounded structured data, sitemap and a default noindex review guard.
- Added static WHC/Apache configuration, quality scripts, research, image provenance, lead-operation guidance and a release/rollback checklist.
- Updated the toolchain to Astro 7.4.4 and security-fixed dependencies. No production backend is shipped.
- Public release, DNS, SSL and live delivery tests remain pending owner approval and required operational inputs.
